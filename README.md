# Spendigo

Spendigo is a full-stack personal finance management web application for tracking income and expenses, monitoring financial activity, and viewing spending insights through a clean dashboard.

## Features

* User registration and authentication
* Dashboard with financial overview
* Income and expense tracking
* Transaction search and filtering
* Custom transaction categories
* Monthly income and expense charts
* Spending breakdown by category
* Reports and analytics
* Profile management
* Profile photo upload
* Password management
* Dark mode
* Responsive interface
* Skeleton loading states

## Tech Stack

## Getting Started

### Requirements

* PHP 8+
* MySQL
* Node.js
* npm
* XAMPP or another PHP/MySQL environment

### 1. Clone the repository

```bash
git clone <repository-url>
cd Spendigo
```

### 2. Backend setup

Configure the database connection and required environment variables according to the backend configuration.

Create the required MySQL database and import the project database schema.

Make sure the PHP API is running through your local PHP server or XAMPP.

### 3. Frontend setup

```bash
cd frontend
npm install
npm run dev
```

The frontend will run on the Vite development server.

## Environment Variables

Do not commit real credentials or secrets to the repository.

Create the required environment files locally and configure:

* API base URL
* Database credentials
* JWT secret
* Other environment-specific settings
